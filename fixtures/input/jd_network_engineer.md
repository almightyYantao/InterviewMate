# 网络工程师（杭州）

## 岗位职责
1. 负责全球办公网络（杭州、香港、新加坡、东京、美国）的架构设计、建设与日常运维；
2. 负责办公室之间及办公室与新加坡 IDC 之间的跨地域互联（SD-WAN / IPsec / 专线）；
3. 负责防火墙安全策略的规划、治理与审计；
4. 负责有线与无线网络准入（802.1X），与 Keycloak / Google Workspace 身份系统打通；
5. 负责新加坡 IDC 网络（含 GPU 服务器集群、带外管理网络）的规划与运维；
6. 建设网络监控、告警与变更管理流程，参与 7×24 值班。

## 任职要求
1. 5 年以上企业网络工作经验；
2. 熟悉 TCP/IP，熟悉 VLAN、STP、链路聚合等二层技术；
3. 熟悉 OSPF、BGP 路由协议，有大型网络规划经验；
4. **熟悉 Fortinet（FortiGate、FortiSwitch、FortiAP）和 Ubiquiti（UniFi）设备**；
5. 熟悉 IPsec VPN、SD-WAN，有跨国网络互联经验；
6. 熟悉 802.1X、RADIUS 等网络准入技术；
7. 有 IDC 网络建设与运维经验；
8. 有规范的变更管理意识，有大型割接经验；
9. 熟悉 Zabbix / Prometheus 等监控系统；
10. 英语可作为工作语言（读写文档、与海外同事沟通）；
11. 能接受出差及 7×24 值班。

## 加分项
1. 持有 CCNP / HCIP / NSE 等认证优先；
2. 会 Python 自动化优先；
3. 有 GPU 服务器、RDMA 网络经验优先。
